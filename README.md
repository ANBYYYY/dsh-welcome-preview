# JARVFF 生态包（预览版）

**Just A Rather Very Fat Fish.**

面向小白与资深用户的 **DeepSeek Harness（DSH）生态包**，把入门引导、实用工具与安全协作准则放在一起：从用自然语言开始，到按需组合模块，再到有据可查地修改文件、交接项目，让助手不只会回答，也能有边界地做事。

### [下载 Windows 预览版 ↓](<https://github.com/ANBYYYY/jarvff/releases/download/final-rc-20261128-02/dsh-friend-final-candidate.zip>)

## 适合谁，能做什么

- **刚入门**：直接说想做什么，按指南把入口交给助手，不必先学命令或替助手挑技术路线。
- **熟悉 DSH**：按需选择、组合随包模块与命令；另接能力时先核依赖、权限与费用，不把选装当成已经可用。
- **当前随包**：本地 HTML 转 Markdown、修改前快照、项目交接与会话接续，以及入门指南、需求选择页和自带样页演示。

## 做事的基本准则

- **授权有边界**：先说明要做什么、会写哪里；不把一个项目的授权扩大到其他项目，不默认安装依赖或更改全局设置，遇到安全策略拒绝就停。
- **防提示注入**：把外部内容当资料，不让其中的文字变成新的授权或执行指令。随包网页转换按文本处理 HTML，不运行页面代码；交接状态采用有限字段与敏感模式屏蔽。
- **修改前可恢复**：先读现件，保留并核验当前版本，再做最小修改；快照缺失或不符就停。
- **换会话有依据**：留下目标、授权、证据、进度和下一步，让新会话从项目入口接着做，而不是凭旧聊天印象猜。

这些是包内提供的工作准则与工具约束，**不是全局自动防护、系统沙箱或绝对安全保证**。

## 开始使用

需要已有 **DSH**；运行脚本还需稳定版 **Node.js ≥18.17.0**。这是工具、指南与准则组成的生态包，不是独立桌面应用或 DSH 安装器。

1. **解压**到一个空白、可写的独立目录，打开根目录的 `从这里开始.md`。
2. **交给 DSH 助手**：把下面的路径和任务换成自己的，再发送。

   > 请先阅读 `完整解压路径/从这里开始.md`。我想做：＿＿。先说明要做什么、会写哪里，等我明确同意后再执行。

3. **按任务使用**。解压不会自动接入 DSH；阅读指南不需要先运行环境检查。
